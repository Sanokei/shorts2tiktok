2 · TikTok
  1. Sign in at developers.tiktok.com/apps and create an app.
  2. Add the Login Kit and Content Posting API products to it.
  3. On the app page, create a Sandbox and add your own TikTok account to it as a target user. A sandbox works without waiting for TikTok to review the app.
  4. Give the sandbox the scopes user.info.basic and video.upload.
  5. Under Platforms, tick Desktop, then register a redirect URI on the Desktop tab. Try http://127.0.0.1:8713/callback first.
  6. If the console answers localhost is not supported, it wants a real address. Put any https page you control in the Redirect URI box below and register that same string instead. TikTok will send you there with the code in the address bar, and you paste it back here.
  7. Copy the client key and client secret from the app page into the boxes above.

The registration form also wants an icon, a description, and two policy URLs. All of that is written out ready to paste in tiktok-app-details.md, with the icon at assets/icon.png and the policy text in docs/.

Ignore Verify domains. That is only for having TikTok pull a video off a public URL. This app sends the file bytes straight up, so you never host anything.

Full review is only needed for direct posting to a public profile. It wants a privacy policy URL, a verified domain, and a demo video, and takes a week or two.

This must match the string registered on your TikTok app character for character. A loopback address runs the desktop sign-in flow and catches the code automatically. Any other https address runs the web flow, and you finish by pasting the address bar into the box under Connect TikTok.
Inbox mode needs only video.upload and runs inside a sandbox, so no review.

Find them on your phone, not on the web. Open the TikTok mobile app, tap Inbox in the bottom row, open System notifications, and look for Your content is ready. That opens the normal editor where you write the caption, add sound, and post. They will not show up in TikTok Studio or on your profile until you do.

Direct mode needs video.publish and a reviewed app, and an unreviewed one forces every post to private.

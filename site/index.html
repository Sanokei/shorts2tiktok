Shorts Porter

A desktop tool for moving your own short videos from your own YouTube channel to your own TikTok account.

It runs on the machine of the person who installed it. There is no hosted service, no account to create, and nothing in the request path between you and the two platforms. This page exists because both platforms ask an application to publish a policy before they will issue it credentials.

How it works

  1. It reads the list of Shorts on your channel through the YouTube Data API, using an API key you created.
  2. You pick which ones to move.
  3. It downloads those videos and uploads them to your TikTok account through the Content Posting API.
  4. Each upload lands in your own TikTok inbox. You write the caption and publish from inside the TikTok app.

What it does not do

  • It does not publish anything on its own. A person completes every post.
  • It does not touch accounts other than the one that signed in.
  • It does not send data anywhere except Google and TikTok.
  • It does not collect analytics, and it has no server to collect them with.

Credentials

Keys and tokens live in a single file on the operator's own disk. Deleting the folder deletes them. Access can be withdrawn at any time from the connected apps list in TikTok's own settings.
